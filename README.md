# BD SME Cyber + AI Kit

বাংলাদেশের ছোট ব্যবসা, ফ্রিল্যান্সার ও পেজ অ্যাডমিনদের জন্য সংক্ষিপ্ত চেকলিস্ট ও প্রম্পট।

এই রিপোতে হ্যাকিং, অ্যাকাউন্ট ব্রেক, এক্সপ্লয়েট বা বাইপাস নেই। শুধু প্রতিরোধ ও সচেতনতা।

[English overview](en/overview.md)

## কেন স্টার দেবেন

- বাংলায় লেখা, প্রিন্ট করে টিমে পিন করা যায়
- Gmail, ফেসবুক পেজ, ফিশিং, AI টুল — এক জায়গায়
- ক্লায়েন্টের পাসওয়ার্ড বা ডেটা AI-তে না দেওয়ার স্পষ্ট নিয়ম
- কোনো টুল সেল নেই, কোনো “রিকভারি সার্ভিস” নেই

## কাদের জন্য

- দোকান, এজেন্সি, পেজ মালিক
- যে কেউ ক্লায়েন্টের মেইল বা ফাইল হাতে রাখেন
- যে কেউ চ্যাটজিপিটি / ইমেজ টুল ব্যবসায় ব্যবহার করেন

## ব্যবহার

1. প্রয়োজনীয় চেকলিস্ট খুলুন
2. প্রিন্ট করুন বা টিম চ্যাটে পিন করুন
3. মাসে একবার [monthly-review](checklists/monthly-review-bn.md) ঘুরে দেখুন

## সীমা

হারিয়ে যাওয়া অ্যাকাউন্ট ফেরত পেতে শুধু অফিসিয়াল রিকভারি ফর্ম ও প্ল্যাটফর্ম সাপোর্ট ব্যবহার করুন। তৃতীয় পক্ষের “রিকভারি সার্ভিস” এড়িয়ে চলুন।
