# ক্লায়েন্ট ডেটা — AI ব্যবহারের নিয়ম

টিম বা ফ্রিল্যান্সারকে দেওয়ার জন্য কপি করুন।

1. ক্লায়েন্টের পাসওয়ার্ড, OTP, কাস্টমার লিস্ট, ইনভয়েস এক্সপোর্ট কোনো চ্যাটজিপিটি / ক্লড / ইমেজ টুলে যাবে না।
2. উদাহরণ লাগলে নাম-ফোন মুছে নমুনা বানাবেন।
3. ক্লায়েন্ট ছবি ব্যবহারের আগে লিখিত অনুমতি।
4. অ্যাকাউন্ট রিকভারি শুধু অফিসিয়াল ফর্ম। তৃতীয় পক্ষ সার্ভিস নিষিদ্ধ।
5. এই নিয়ম ভাঙলে কাজ বন্ধ।
